# Local LLM Inference Engines

Engines and runtimes for running LLMs locally and self-hosted, from llama.cpp and Ollama to Apple Silicon MLX engines and production GPU serving.

[Back to README](../../../readme.md)

| **Name**         | **Key Features/Notes**                                                                                                                                                                                                                                                                       | **Source**                                           |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------- |
| **llama.cpp**    | The foundational C/C++ inference engine for consumer hardware; defines the GGUF format, runs on macOS, Windows, Linux, mobile and WebAssembly with CPU or GPU, and underpins Ollama, LM Studio, KoboldCpp and GPT4All.                                                                       | [GitHub](https://github.com/ggml-org/llama.cpp)      |
| **Ollama**       | One-command local LLM runner for macOS, Windows and Linux; GGUF models from a built-in registry, with OpenAI- and Anthropic-compatible APIs on localhost; the developer default for quick local testing.                                                                                     | [Ollama](https://ollama.com/)                        |
| **LM Studio**    | Desktop app for browsing, downloading and chatting with local models (GGUF and MLX backends), with an OpenAI-compatible local server and a headless llmster daemon; closed-source, free for personal use.                                                                                    | [LM Studio](https://lmstudio.ai/)                    |
| **vLLM**         | High-throughput production serving engine (Linux, GPU): PagedAttention, continuous batching and speculative decoding; wide format support (safetensors, AWQ, GPTQ, FP8); OpenAI-compatible API.                                                                                              | [GitHub](https://github.com/vllm-project/vllm)       |
| **SGLang**       | High-performance serving framework for LLMs and multimodal models: RadixAttention prefix caching, continuous batching and structured outputs; runs from a single GPU to large distributed clusters; OpenAI-compatible API.                                                                   | [GitHub](https://github.com/sgl-project/sglang)      |
| **TensorRT-LLM** | NVIDIA's inference library for maximum performance on NVIDIA GPUs: optimized kernels, in-flight batching, FP8 and NVFP4 quantization; OpenAI-compatible trtllm-serve server.                                                                                                                 | [GitHub](https://github.com/NVIDIA/TensorRT-LLM)     |
| **MLX**          | Apple's open-source ML framework for Apple Silicon, built on unified memory with no CPU-GPU copying; the mlx-lm package adds LLM inference, an OpenAI-compatible server, quantization and LoRA fine-tuning; Python and Swift APIs.                                                           | [GitHub](https://github.com/ml-explore/mlx)          |
| **Splash**       | Apple Silicon engine (M3 or newer, macOS 26.4+) built around per-model DFlash 2 speculative decoding and specialized Metal kernels; automatic prefix reuse and request batching, vision and tool calling; OpenAI and Anthropic APIs aimed at coding agents; GGUF and MLX models; Apache-2.0. | [GitHub](https://github.com/incoai/splash)           |
| **vMLX**         | Apple Silicon engine (M1-M5, macOS 14+, MIT): full-precision paged KV cache that spills to SSD so prefixes survive restarts, continuous batching, speculative decoding and a built-in GGUF-to-MLX converter; OpenAI, Anthropic and Ollama APIs; no account, no telemetry.                    | [vMLX](https://vmlx.net/)                            |
| **oMLX**         | macOS-native MLX server (Apple Silicon, macOS 15+, Apache-2.0): paged SSD KV cache restores prefixes across requests and restarts, continuous batching, multi-model serving (LLM, VLM, embedding, reranker) and a menu-bar app; OpenAI and Anthropic APIs.                                   | [oMLX](https://omlx.ai/)                             |
| **macMLX**       | Native macOS engine whose inference core is Swift and in-process, with no Python anywhere: SwiftUI app, CLI and OpenAI/Anthropic/Ollama APIs on one engine; continuous batching, prompt caching and VLM support; Apple Silicon, macOS 14+, Apache-2.0.                                       | [macMLX](https://macmlx.app/)                        |
| **Strata**       | Cross-platform inference engine (Windows, Linux, macOS; MIT) tuned for very large MoE models on consumer hardware, streaming what does not fit in memory from SSD; one-click install with desktop and terminal apps; OpenAI and Anthropic APIs on localhost.                                 | [GitHub](https://github.com/Niko1221/Strata)         |
| **Exo**          | Distributed inference that pools multiple Macs and other devices peer-to-peer into a single cluster, so models too large for one machine (e.g. 671B MoE) run across their combined memory; alpha.                                                                                            | [GitHub](https://github.com/exo-explore/exo)         |
| **LocalAI**      | Drop-in OpenAI and Anthropic API replacement that runs models locally across multiple backends (llama.cpp, vLLM, MLX and more); text, image, audio, video and embeddings; no GPU required.                                                                                                   | [GitHub](https://github.com/mudler/LocalAI)          |
| **Jan**          | Privacy-first open-source desktop app (AGPL-3.0) that runs GGUF and MLX models fully offline, with hybrid local + cloud model switching and MCP support; macOS, Windows and Linux.                                                                                                           | [GitHub](https://github.com/janhq/jan)               |
| **KoboldCpp**    | Single-executable llama.cpp fork with a built-in web UI: zero-install GGUF inference with KoboldAI, OpenAI and Ollama compatible APIs; popular for creative writing and roleplay.                                                                                                            | [GitHub](https://github.com/LostRuins/koboldcpp)     |
| **GPT4All**      | Desktop app by Nomic AI for running GGUF models privately on consumer hardware, with built-in LocalDocs for chatting with your own documents (local RAG); macOS, Windows and Linux.                                                                                                          | [GitHub](https://github.com/nomic-ai/gpt4all)        |
| **MLC-LLM**      | Machine-learning compilation engine that deploys LLMs natively across GPUs, browsers (WebGPU), phones and CPUs from a single model definition; built on Apache TVM.                                                                                                                          | [GitHub](https://github.com/mlc-ai/mlc-llm)          |
| **mistral.rs**   | Rust inference engine: fast CPU and GPU inference with in-situ quantization, paged attention and multi-GPU support; runs GGUF, GGML and Hugging Face models behind an OpenAI-compatible server.                                                                                              | [GitHub](https://github.com/EricLBuehler/mistral.rs) |
