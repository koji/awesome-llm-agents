# Local LLM Inference Engines

Engines and runtimes for running LLMs locally and self-hosted, from llama.cpp and Ollama to Apple Silicon MLX engines and production GPU serving.

[Back to README](../../../readme.md)

| **Name**         | **Key Features/Notes**                                                                                                                                                                                                                                                                                          | **Source**                                           |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------- |
| **llama.cpp**    | The foundational C/C++ inference engine for consumer hardware; defines the GGUF format and underpins Ollama, LM Studio, KoboldCpp and GPT4All, with CPU or GPU inference. OS: macOS, Windows, Linux, Android, iOS, WebAssembly.                                                                                 | [GitHub](https://github.com/ggml-org/llama.cpp)      |
| **Ollama**       | One-command local LLM runner with a built-in model registry (GGUF) and OpenAI- and Anthropic-compatible APIs on localhost; the developer default for quick local testing. OS: macOS, Windows, Linux.                                                                                                            | [Ollama](https://ollama.com/)                        |
| **LM Studio**    | Desktop app for browsing, downloading and chatting with local models (GGUF and MLX backends), with an OpenAI-compatible local server and a headless llmster daemon; closed-source, free for personal use. OS: macOS, Windows, Linux.                                                                            | [LM Studio](https://lmstudio.ai/)                    |
| **vLLM**         | High-throughput production serving engine: PagedAttention, continuous batching and speculative decoding; wide format support (safetensors, AWQ, GPTQ, FP8); OpenAI-compatible API. OS: Linux (GPU).                                                                                                             | [GitHub](https://github.com/vllm-project/vllm)       |
| **SGLang**       | High-performance serving framework for LLMs and multimodal models: RadixAttention prefix caching, continuous batching and structured outputs; runs from a single GPU to large distributed clusters; OpenAI-compatible API. OS: Linux (also supports Apple Silicon).                                             | [GitHub](https://github.com/sgl-project/sglang)      |
| **TensorRT-LLM** | NVIDIA's inference library for maximum performance on NVIDIA GPUs: optimized kernels, in-flight batching, FP8 and NVFP4 quantization; OpenAI-compatible trtllm-serve server. OS: Linux.                                                                                                                         | [GitHub](https://github.com/NVIDIA/TensorRT-LLM)     |
| **MLX**          | Apple's open-source ML framework built on unified memory with no CPU-GPU copying; the mlx-lm package adds LLM inference, an OpenAI-compatible server, quantization and LoRA fine-tuning; Python and Swift APIs. OS: macOS (Apple Silicon).                                                                      | [GitHub](https://github.com/ml-explore/mlx)          |
| **Splash**       | Apple Silicon engine built around per-model DFlash 2 speculative decoding and specialized Metal kernels; automatic prefix reuse and request batching, vision and tool calling; OpenAI and Anthropic APIs aimed at coding agents; GGUF and MLX models; Apache-2.0. OS: macOS 26.4+ (Apple Silicon, M3 or newer). | [GitHub](https://github.com/incoai/splash)           |
| **vMLX**         | Apple Silicon engine (MIT): full-precision paged KV cache that spills to SSD so prefixes survive restarts, continuous batching, speculative decoding and a built-in GGUF-to-MLX converter; OpenAI, Anthropic and Ollama APIs; no account, no telemetry. OS: macOS 14+ (Apple Silicon, M1-M5).                   | [vMLX](https://vmlx.net/)                            |
| **oMLX**         | MLX server with a paged SSD KV cache that restores prefixes across requests and restarts, continuous batching, multi-model serving (LLM, VLM, embedding, reranker) and a menu-bar app; OpenAI and Anthropic APIs; Apache-2.0. OS: macOS 15+ (Apple Silicon).                                                    | [oMLX](https://omlx.ai/)                             |
| **macMLX**       | Native engine whose inference core is Swift and in-process, with no Python anywhere: SwiftUI app, CLI and OpenAI/Anthropic/Ollama APIs on one engine; continuous batching, prompt caching and VLM support; Apache-2.0. OS: macOS 14+ (Apple Silicon).                                                           | [macMLX](https://macmlx.app/)                        |
| **Strata**       | Inference engine tuned for very large MoE models on consumer hardware, streaming what does not fit in memory from SSD; one-click install with desktop and terminal apps; OpenAI and Anthropic APIs on localhost; MIT. OS: Windows, Linux, macOS.                                                                | [GitHub](https://github.com/Niko1221/Strata)         |
| **Exo**          | Distributed inference that pools multiple devices peer-to-peer into a single cluster, so models too large for one machine (e.g. 671B MoE) run across their combined memory; alpha. OS: macOS, Linux, iOS.                                                                                                       | [GitHub](https://github.com/exo-explore/exo)         |
| **LocalAI**      | Drop-in OpenAI and Anthropic API replacement that runs models locally across multiple backends (llama.cpp, vLLM, MLX and more); text, image, audio, video and embeddings; no GPU required. OS: Linux, macOS, Windows.                                                                                           | [GitHub](https://github.com/mudler/LocalAI)          |
| **Jan**          | Privacy-first open-source desktop app (AGPL-3.0) that runs GGUF and MLX models fully offline, with hybrid local + cloud model switching and MCP support. OS: macOS, Windows, Linux.                                                                                                                             | [GitHub](https://github.com/janhq/jan)               |
| **KoboldCpp**    | Single-executable llama.cpp fork with a built-in web UI: zero-install GGUF inference with KoboldAI, OpenAI and Ollama compatible APIs; popular for creative writing and roleplay. OS: Windows, Linux, macOS, Android.                                                                                           | [GitHub](https://github.com/LostRuins/koboldcpp)     |
| **GPT4All**      | Desktop app by Nomic AI for running GGUF models privately on consumer hardware, with built-in LocalDocs for chatting with your own documents (local RAG). OS: macOS, Windows, Linux.                                                                                                                            | [GitHub](https://github.com/nomic-ai/gpt4all)        |
| **MLC-LLM**      | Machine-learning compilation engine that deploys LLMs natively from a single model definition; built on Apache TVM. OS: Windows, Linux, macOS, iOS, Android, Web (WebGPU).                                                                                                                                      | [GitHub](https://github.com/mlc-ai/mlc-llm)          |
| **mistral.rs**   | Rust inference engine: fast CPU and GPU inference with in-situ quantization, paged attention and multi-GPU support; runs GGUF, GGML and Hugging Face models behind an OpenAI-compatible server. OS: Linux, macOS, Windows.                                                                                      | [GitHub](https://github.com/EricLBuehler/mistral.rs) |
